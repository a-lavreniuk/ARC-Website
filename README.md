# ARC-Website

Русскоязычный статический сайт ARC на Astro. React используется только для интерактивных демонстраций. Репозиторий сайта отделён от репозитория Windows-приложения.

## Локальный запуск

```sh
npm install
npm run dev
```

## Страницы

- `/` — hero и интерактивное демо первого экрана.
- `/ui-kit` — каталог мастер-компонентов, закрытый от индексации.

Публичную отправку заявок и релизную загрузку включать после настройки соответствующих источников данных.
